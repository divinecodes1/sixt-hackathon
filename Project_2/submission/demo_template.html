How the estimate reaches an analyst

Runs locally · no API key
01 Respect what was known

Use the readings and rental records available at the estimate date. An old value in a new status update is not automatically a fresh reading.

02 Estimate and show a range

Compare simple and rental-aware models. Select using earlier validation data and calibrate prediction ranges separately.

03 Send exceptions to review

Show discrepancies with a reason and context. Valuation and defleet teams retain control over decisions.
