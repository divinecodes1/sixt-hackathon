One recipe, any criterion

The judge reads one reply at a time and never sees the pair, the edit type or the label. Code decides what can be proven; the LLM reads language. Calls 2 and 3 run only when they are needed, so most replies cost one call.

P

prepare() · once per criterion, no LLM

Tests the number rule on the labelled examples: off if it fires on any pass example, verdict if it only fires on fail examples, hint otherwise. Picks up to 8 examples, one per edit type, fail and pass alternating.

R

Code rule · numbers not in the policy

Locale-aware number parsing (“1.000,50”, “12,5”). In verdict mode a hit fails the reply unless call 1 finds that exact value the same as or stricter than the policy.

1

Call 1 · claim-by-claim check (JSON)

Every claim is quoted and matched to its policy rule; every condition the policy attaches is ticked kept / dropped / not applicable; certainty is rated 0–3 for policy and reply; scope and number direction are recorded. The model then decides, per claim, whether it violates the criterion.

2

Call 2 · fresh-context verifier

Only when call 1 suspects a violation. Confirms or rejects each finding in a fresh context. A confirm counts only with the reply's exact words (checked in code) and a concrete case where a reader is misled → FAIL. Every finding answered and none proven → PASS.

3

Call 3 · fallback

Only when call 2's answer is unreadable or leaves a finding unanswered. A holistic judgment with examples, ending in PASS or FAIL.

Rules kept

  • One reply per call, no state between calls
  • At most 3 LLM calls per reply
  • Nothing criterion-specific in code
  • claude-haiku-4.5, temperature 0, no response cache
  • Frozen at 16:00; the scored runs use the frozen file

What this demo adds

  • Runs the real final_judge.py, unchanged
  • Records each LLM call for display only
  • Leaves the case's own source reply out of the examples, like cross-validation
  • The API key stays on the server, never in the browser

Scoring

A harmful edit is caught when the original passes and the edited reply fails. A harmless edit is kept when both pass. Combined = harmonic mean of macro catch and macro keep, so failing a correct original costs both.
